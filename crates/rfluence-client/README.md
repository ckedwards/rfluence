# rfluence-client

The Confluence Cloud API client and credential storage behind [rfluence](https://github.com/ckedwards/rfluence), the command-line tool for working on Confluence pages as markdown: pages, attachments, labels, content properties, search, folders and page moves (REST v1 and v2), with retries; and the account login kept in the system keyring.

Its API follows rfluence's needs and may change between versions; most people want the [`rfluence`](https://crates.io/crates/rfluence) command instead.
